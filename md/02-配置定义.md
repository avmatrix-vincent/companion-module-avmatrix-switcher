# Companion 模块开发 - 配置定义 (User-Config)

> 文档来源：https://companion.free/for-developers/module-development/connection-basics/user-configuration/

## 概述

模块配置类似于连接的首选项，例如受控设备的 IP 地址。配置对象本身是由开发者定义的 JavaScript 对象。在 TypeScript 中，创建类型或接口来定义配置对象，然后在声明 InstanceBase 类时使用该类型。

自 API 1.13 (Companion 4.1) 起支持 Secrets 功能。将字段定义为 secret 后，Companion 会将其值存储在单独的 secrets 对象中，避免日志记录，并允许用户在导出配置时轻松省略这些值。

## 核心 API

### getConfigFields(): SomeCompanionConfigField[]

当用户打开配置面板时，Companion 调用此方法以呈现正确的字段。

### saveConfig(newconfig)

如果需要以编程方式更改配置对象（例如保存持久状态或允许动作更改配置），调用此方法。**不会触发 configUpdated()**。

### configUpdated(config, secrets): Promise<void>

用户更改配置时调用。通常在此销毁现有连接并使用新配置重新建立。

`init()`、`configUpdated()`、`saveConfig()` 在定义 secret 字段时都会涉及 secrets 对象。

## 配置字段定义

配置字段与动作/反馈的选项字段类似，但限制更多。所有字段必须包含 `width` 属性（1-12），指定在 UI 中占据的列数。

**注意**：配置和 secrets 对象的内容必须是 JSON 安全值。

### 可用字段类型

- `static-text` - 静态文本
- `textinput` - 文本输入
- `number` - 数字输入
- `dropdown` - 下拉选择
- `multidropdown` - 多选下拉
- `checkbox` - 复选框
- `colorpicker` - 颜色选择器
- `secret-text` - 密钥文本（仅 User-Config）
- `bonjour-device` - Bonjour 设备发现（仅 User-Config）

### 字段可见性控制

#### isVisibleExpression (API 1.12+)

使用 Companion 表达式语法控制字段显示/隐藏：

```js
{
  type: 'number',
  id: 'speed',
  label: 'Speed',
  isVisibleExpression: '$(options:mode) == "manual"',
}
```

表达式只能引用 `$(options:fieldId)` 命名空间中的字段，不支持引用真正的 Companion 变量。

在配置定义中，任何配置字段都可以自由引用。在动作/反馈中，只能引用设置了 `disableAutoExpression: true` 的字段。

#### isVisible (已弃用，API 2.0 移除)

API 1.12 之前的函数式可见性控制，API 2.0 中会被静默忽略，必须迁移到 `isVisibleExpression`。

迁移示例：
```js
// 之前
"isVisible": (opts) => !!opts.otherField
// 之后
"isVisibleExpression": `!!$(options:otherField)`
```

## 设备发现

如果设备通过网络连接并支持 Bonjour 协议，可以实现设备自动发现。详见 Bonjour Device Discovery 高级主题。

## 代码示例

```typescript
import { Regex, type SomeCompanionConfigField } from '@companion-module/base'

export interface ModuleConfig {
  host: string
  port: number
}

export function GetConfigFields(): SomeCompanionConfigField[] {
  return [
    {
      type: 'textinput',
      id: 'host',
      label: 'Target IP',
      width: 8,
      regex: Regex.IP,
    },
    {
      type: 'number',
      id: 'port',
      label: 'Target Port',
      width: 4,
      min: 1,
      max: 65535,
      default: 8000,
    },
  ]
}
```

# Companion 模块开发 - 设置自定义变量

> 文档来源：https://companion.free/for-developers/module-development/connection-advanced/setting-custom-variables/

## 概述

**警告**：这是一个实验性功能，可能会在没有通知的情况下移除。

建议优先考虑使用 value feedbacks，让用户将反馈值存储到本地变量中。

有时动作会产生一些用户可能想要使用的数据。这种情况下，不适合将其写入模块变量，因为同个按钮上的其他动作可能很快覆盖它。

替代方案是将数据输出到 custom-variable（自定义变量）。

## 实现方式

### 1. 添加 custom-variable 输入字段

在动作定义中添加类型为 `custom-variable` 的选项：

```js
{
  id: 'result',
  type: 'custom-variable',
  label: 'Result variable',
}
```

选项会自动填充可用的自定义变量列表。

### 2. 在回调中设置值

在动作回调中调用 `this.setCustomVariableValue()`：

```js
callback: (action) => {
  const result = 'Your value'
  this.setCustomVariableValue(action.options.result, result)
}
```

**注意**：如果变量 id 无效，不会收到通知。

## 规则与限制

- 这些变量属于用户，只应在被要求时更改
- 必须是用户主动选择（opt-in），输入字段默认值为 None，必须尊重此设置
- 不得在动作结果之外的时间设置自定义变量的值
- 不得通过此输入字段的值以外的任何方式尝试发现自定义变量

## 示例

```typescript
{
  name: 'Get Status',
  options: [
    {
      id: 'result',
      type: 'custom-variable',
      label: 'Store result to',
    },
  ],
  callback: async (action) => {
    const status = await fetchDeviceStatus()
    if (action.options.result) {
      this.setCustomVariableValue(action.options.result, status)
    }
  },
}
```

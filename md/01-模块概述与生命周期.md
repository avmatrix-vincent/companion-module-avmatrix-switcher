# Companion 模块开发 - 概述与生命周期

> 文档来源：https://companion.free/for-developers/module-development/
> 基于 @companion-module/base API 2.x 整理

## 什么是 Companion 模块

Companion 使用插件（称为模块）来扩展其功能。每个可控制的设备都有一个模块来管理连接。

## 开发环境准备

1. 安装 Companion（建议使用当前稳定版本，确保用户能直接使用）
2. 创建模块开发文件夹
3. 在 Companion Launcher 设置中指定 Developer modules path
4. 下载 TypeScript 模板或复制现有模块
5. 重命名目录为 `companion-module-mymanufacturer-myproduct`
6. 修改 package.json、companion/manifest.json、companion/HELP.md 中的名称和描述
7. 运行 `yarn install` 安装依赖

## 模块文件结构（推荐）

```
src/
  main.ts       # 模块主类，继承 InstanceBase
  config.ts     # 配置字段定义
  actions.ts    # 动作定义
  feedbacks.ts  # 反馈定义
  variables.ts  # 变量定义
  presets.ts    # 预设定义
  upgrades.ts   # 升级脚本
companion/
  manifest.json # 模块清单
  HELP.md       # 用户帮助文档
package.json
```

## 模块类定义

### 导出模块类（API 2.x）

在 `src/main.ts` 中导出模块类：

```typescript
export default class ModuleInstance extends InstanceBase<ModuleConfig> {
  // ...
}
export const UpgradeScripts = [...]
```

API 1.x 使用 `runEntrypoint(ModuleInstance, UpgradeScripts)`，API 2.x 不再支持。

### TypeScript 泛型定义

```typescript
export interface InstanceTypes {
  config: JsonObject
  secrets: JsonObject | undefined
  actions: Record<string, CompanionActionSchema<CompanionOptionValues>>
  feedbacks: Record<string, CompanionFeedbackSchema<CompanionOptionValues>>
  variables: CompanionVariableValues
}
```

可以为每个部分定义具体类型以获得更强的类型检查。

## 生命周期方法

### constructor(internal)

构造函数，在模块实例化时调用。此时 Companion 尚未准备好与模块交互，只应进行少量初始化设置（如创建对象、初始化属性）。随后会调用 `init()`。

### init(config, isFirstInit, secrets): Promise<void>

Companion 准备好运行模块时调用。

- `config`: 用户配置对象
- `isFirstInit`: 首次初始化时为 true
- `secrets`: 密钥对象

此方法中应存储配置、建立连接、设置逻辑。**注意：不可等待连接完成，否则 Companion 会认为超时并重启模块。**

### configUpdated(config, secrets): Promise<void>

用户更新模块配置时调用。通常应销毁现有连接并根据新配置重新建立。

### destroy(): Promise<void>

模块停止时调用。应优雅地终止连接、清理定时器、防止内存泄漏。

### getConfigFields(): SomeCompanionConfigField[]

用户编辑配置时调用，返回配置面板字段定义。

## 常用工具方法

### log(level, message)

向 Companion 日志写入消息。

### updateStatus(status, message?)

更新模块连接状态，使用 `InstanceStatus` 枚举值：
- `InstanceStatus.Ok` - 连接正常
- `InstanceStatus.Connecting` - 正在连接
- `InstanceStatus.Disconnected` - 已断开
- `InstanceStatus.ConnectionFailure` - 连接失败
- `InstanceStatus.BadConfig` - 配置错误
- `InstanceStatus.UnknownError` - 未知错误

## 开发提示

- 保存文件时 Companion 会自动重启使用该模块的连接
- 模块在 Connections 页面可见，但在 Modules 页面不可见（因为尚未成为官方模块）
- 从 v4.0 开始，模块发布周期与 Companion 发布周期解耦

# Companion 模块开发 - 输入字段类型 (Input Fields / Options)

> 文档来源：https://companion.free/for-developers/module-development/connection-basics/input-field-types/

## 概述

Companion 提供标准化的输入字段集合，可用于动作定义、反馈定义和模块配置定义。不同场景下可用类型略有差异。

## 通用字段属性

所有输入类型都有一些通用属性，每个类型还有额外的专属属性：

```javascript
{
  type: 'number',
  id: 'source',
  label: 'Source',
  default: 1,
}
```

## 可用字段类型

### 通用类型（动作、反馈、配置均可用）

| 类型 | 说明 |
|------|------|
| `static-text` | 静态文本，用于显示说明信息 |
| `textinput` | 文本输入框 |
| `colorpicker` | 颜色选择器 |
| `dropdown` | 下拉选择 |
| `multidropdown` | 多选下拉 |
| `checkbox` | 复选框 |
| `number` | 数字输入 |

### 动作专属

| 类型 | 说明 |
|------|------|
| `custom-variable` | 自定义变量选择 |

### 配置专属

| 类型 | 说明 |
|------|------|
| `secret-text` | 密钥文本（值存入 secrets 对象） |
| `bonjour-device` | Bonjour 设备发现 |

完整的字段类型属性说明请参考自动生成的 API 文档（GitHub 上 @companion-module/base 的文档）。

## 字段可见性控制

### isVisibleExpression (API 1.12+)

使用 Companion 表达式语法条件显示/隐藏字段：

```js
{
  type: 'number',
  id: 'speed',
  label: 'Speed',
  isVisibleExpression: '$(options:mode) == "manual"',
}
```

规则：
- 只能引用 `$(options:fieldId)` 命名空间
- 不支持引用真正的 Companion 变量
- 在配置定义中：可引用任何配置字段
- 在动作/反馈中：只能引用设置了 `disableAutoExpression: true` 的字段

### isVisible (已弃用，API 2.0 移除)

函数式可见性控制，API 2.0 中被静默忽略：

```js
// 之前（API 1.12 之前）
{
  type: 'number',
  id: 'speed',
  label: 'Speed',
  isVisible: (opts) => opts.mode === 'manual',
}

// 之后（迁移到 isVisibleExpression）
{
  type: 'number',
  id: 'speed',
  label: 'Speed',
  isVisibleExpression: '$(options:mode) == "manual"',
}
```

## 示例

```javascript
options: [
  {
    type: 'static-text',
    id: 'info',
    label: 'Note',
    value: 'This action controls the main output',
  },
  {
    type: 'dropdown',
    id: 'camera',
    label: 'Select Camera',
    choices: [
      { id: 'a', label: 'Camera A' },
      { id: 'b', label: 'Camera B' },
    ],
    default: 'a',
  },
  {
    type: 'number',
    id: 'brightness',
    label: 'Brightness',
    default: 50,
    min: 0,
    max: 100,
    isVisibleExpression: '$(options:mode) == "manual"',
  },
]
```

# Companion 模块开发 - 网络连接 (TCP/Telnet/UDP)

> 文档来源：https://companion.free/for-developers/module-development/connection-basics/

## 概述

如果模块通过网络连接设备，`@companion-module/base` 提供了三个辅助类来简化网络连接管理：

- `TCPHelper` - TCP 连接
- `TelnetHelper` - Telnet 连接
- `UDPHelper` - UDP 连接

## TCPHelper

用于建立 TCP 套接字连接。在 `init()` 或 `configUpdated()` 中设置连接，在回调中处理数据接收和状态变更。

基本使用模式：

```typescript
import { TCPHelper, InstanceStatus } from '@companion-module/base'

async init(config) {
  this.config = config
  
  this.tcp = new TCPHelper(config.host, config.port)
  
  this.tcp.on('status_change', (status, message) => {
    this.updateStatus(status, message)
  })
  
  this.tcp.on('data', (data) => {
    this.processData(data)
  })
  
  this.tcp.on('error', (err) => {
    this.log('error', `TCP error: ${err.message}`)
  })
}

async destroy() {
  if (this.tcp) {
    this.tcp.destroy()
    this.tcp = undefined
  }
}
```

## TelnetHelper

基于 TCPHelper 构建，增加了 Telnet 协议协商支持。适用于需要通过 Telnet 协议通信的设备。

使用方式与 TCPHelper 类似，但会自动处理 Telnet 选项协商。

## UDPHelper

用于 UDP 通信，适用于无连接或广播场景。

基本使用模式：

```typescript
import { UDPHelper } from '@companion-module/base'

async init(config) {
  this.udp = new UDPHelper(config.host, config.port)
  
  this.udp.on('status_change', (status, message) => {
    this.updateStatus(status, message)
  })
  
  this.udp.on('data', (data) => {
    this.processData(data)
  })
  
  this.udp.on('error', (err) => {
    this.log('error', `UDP error: ${err.message}`)
  })
}

// 发送数据
sendCommand(cmd) {
  if (this.udp) {
    this.udp.send(cmd)
  }
}
```

## 连接状态管理

在网络连接的回调中，应使用 `updateStatus()` 更新模块状态：

```typescript
this.updateStatus(InstanceStatus.Connecting)
this.updateStatus(InstanceStatus.Ok)
this.updateStatus(InstanceStatus.ConnectionFailure, err.message)
```

## 注意事项

1. **不要在 `init()` 中等待连接完成**：这会导致 Companion 认为模块超时并重启它
2. **在 `destroy()` 中清理连接**：防止内存泄漏和端口占用
3. **在 `configUpdated()` 中重建连接**：先销毁旧连接，再用新配置建立新连接
4. **处理错误事件**：网络错误应记录日志并更新状态，避免未处理的异常导致模块崩溃

## 代码示例

```typescript
import { InstanceBase, InstanceStatus, TCPHelper } from '@companion-module/base'

export class ModuleInstance extends InstanceBase<ModuleConfig> {
  private tcp: TCPHelper | undefined

  async init(config: ModuleConfig): Promise<void> {
    this.config = config
    this.setupConnection()
  }

  async configUpdated(config: ModuleConfig): Promise<void> {
    this.config = config
    this.destroyConnection()
    this.setupConnection()
  }

  async destroy(): Promise<void> {
    this.destroyConnection()
  }

  private setupConnection(): void {
    this.tcp = new TCPHelper(this.config.host, this.config.port)
    
    this.tcp.on('status_change', (status, message) => {
      this.updateStatus(status, message)
    })
    
    this.tcp.on('data', (data) => {
      this.handleData(data.toString())
    })
    
    this.tcp.on('error', (err) => {
      this.log('error', `Connection error: ${err.message}`)
    })
  }

  private destroyConnection(): void {
    if (this.tcp) {
      this.tcp.destroy()
      this.tcp = undefined
    }
  }

  private handleData(data: string): void {
    // 处理设备返回的数据
    this.log('debug', `Received: ${data}`)
  }
}
```
